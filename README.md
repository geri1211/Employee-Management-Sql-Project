# 🗄️ Employee Management System – SQL Project

## 📖 Overview
This project focuses on advanced SQL query development within an Employee Management System database.

It demonstrates the ability to extract, manipulate, and analyse data using complex SQL queries, including joins, subqueries, aggregations, and transactions.

The project simulates real-world business requirements such as employee analysis, sales reporting, and organisational insights.

---

## 🚀 Features

### 👨‍💼 Employee Analysis
- Identify highest paid employees  
- Compare employee salaries with managers  
- Find employees earning more than their managers  
- Detect employees returning to previous roles  

---

### 🏢 Department & Management Insights
- Retrieve managers responsible for departments  
- Analyse employee distribution across regions  
- Handle employees without assigned departments  

---

### 💰 Sales & Customer Analysis
- Calculate:
  - Largest sale per customer  
  - Total sales per customer  
  - Average sales  
  - Number of transactions  
- Compute percentages and performance metrics  

---

### 📊 Advanced SQL Queries
- Multi-table joins  
- Subqueries (nested queries)  
- Aggregate functions (SUM, AVG, COUNT, MAX)  
- Sorting and filtering without hardcoding values  

---

### 🔄 Transactions & Data Manipulation
- Perform updates using dynamic queries  
- Delete and insert records  
- Use transactions to ensure data consistency (COMMIT)  

---

## 🧪 Key SQL Concepts Demonstrated
- Joins (INNER, LEFT, etc.)  
- Subqueries  
- Aggregate Functions  
- Grouping and Filtering  
- Transactions (DML)  
- Data Modelling (ERD)
